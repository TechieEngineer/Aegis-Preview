# Aegis — Interactive Preview

A dependency-free static portfolio demo of the Aegis dashboard. Open `index.html` in a browser or publish the root of this repository using GitHub Pages.

Includes fictional telemetry, role exploration, an offline sample audit report and a simulated one-time envelope. No network checks, real authentication, secret encryption or storage occur. No backend is connected. Do not enter sensitive data.
